# 需求

## 1. 目标

在 Linux 上玩国服原神时，把角色位置实时算出来并**以通用方式交付给任意显示端**。
首个显示端是 `v3.yuanshen.site` 网页地图（跟随并居中），但这不是唯一的、也不是架构的中心。

一句话边界：**本项目只产出「我在哪」，不产出地图、不产出点位、不产出客户端。**

## 2. 非目标

- 不 fork / 不重建网页前端，不做桌面客户端外壳（显示端是适配器，不是本项目主体）
- 不做自动打点、路线规划、自动传送、任务提示
- 不读游戏内存、不注入进程、不 hook 渲染管线
- 不做账号相关功能（登录、同步、收藏）
- 不做多语言界面（首个适配器只有一层面板）

## 3. 术语

| 词 | 含义 |
|---|---|
| frame | 坐标系的规范标识，如 `genshin-map` |
| Position | 一次位置观测（唯一的数据结构，见 interfaces.md） |
| 位置源 (source) | 产出 Position 的组件 |
| 采集 (capture) | 从平台拿像素的组件 |
| 底图 (map provider) | 提供「像素 ↔ frame 坐标」参照与瓦片的组件 |
| 总线 (bus) | Position 的传输通道 |
| 显示适配器 (adapter) | 消费 Position 并呈现的组件 |
| ROI | 感兴趣区域，这里指小地图矩形 |

## 4. 用户流程

1. 起总线（本地服务）→ 起位置源（自动等游戏窗口）
2. 打开任一双端：网页地图页（脚本已注入）或终端（CLI 适配器）
3. 进游戏 → 显示端跟着走
4. 手动拖地图 / 关掉跟随 → 该适配器自行暂停，不影响其他适配器

## 5. 功能需求

| ID | 需求 | 验收标准 | 阶段 |
|---|---|---|---|
| FR-1 | 总线：发布/读取最新 Position，支持多订阅者 | 两个适配器同时连上都能各自收到；非法输入 400 | M0 ✅ |
| FR-2 | 参考适配器 `leaflet-web`：把 Position 换算成地图 LatLng 并居中 | 自检回环（读中心→回喂→地图不动）通过 | M0 ✅ |
| FR-3 | 采集：只取 ROI 像素，失败退避，窗口消失即暂停 | 单帧采集 < 20 ms，断流 5 s 内自动重连 | M1 |
| FR-4 | ROI 标定：一次性标定并落盘，按窗口尺寸复用 | 换分辨率可重新标定而不用改代码 | M1 |
| FR-5 | 定位：固定尺度平移搜索（无旋转），输出坐标 + 置信度 | 静止时偏差 ≤ 10 m；置信度 < 0.55 不上报 | M2 |
| FR-6 | 底图端口 `yuanshen-tiles`：按需下载、本地缓存、可清理 | 断网时已缓存区域可用 | M2 |
| FR-7 | 地理参照：瓦片像素与 frame 坐标互转，误差 ≤ 半块瓦片 | 与网页地图同位置对得上 | M2 |
| FR-8 | 节流：位移 > 1 m 或距上次 > 1 s 才发布 | 静止时总线无写入 | M2 |
| FR-9 | 掩膜：排除玩家箭头、边缘 UI 环、图标层 | 密集点位区域不误判 | M2 |
| FR-10 | 降级：定位失败保持上次值并标 `stale`，不跳变 | 30 分钟不出现乱跳 | M3 |
| FR-11 | **端口化**：五个端口各有至少一个回放/假实现 | 不启动游戏即可跑通端到端回归 | M3 |
| FR-12 | **第二个适配器**：证明新增显示端不必改位置源 | 新增 `cli` 适配器，改动只落在 `adapters/` | M3 |
| FR-13 | frame 声明：Position 必须带 frame，适配器不认识就拒收 | 造一个未知 frame，适配器报错而非错位显示 | M3 |

## 6. 非功能需求

- **依赖**：Python 3.13 + numpy 必需；OpenCV 可选（缺失时走 numpy 实现）
- **开销**：单核 < 15%，常驻 < 200 MB
- **延迟**：画面变化 → 显示端更新 < 1.5 s
- **权限**：不需要 root
- **网络**：除首次下载瓦片外离线可用
- **可观测**：每个端口的输入输出都能落到滚动日志，能区分「没截到 / 没匹配上 / 没送达」

## 7. 里程碑

| 阶段 | 内容 | 出口判据 |
|---|---|---|
| M0 ✅ | 总线 + `leaflet-web` 适配器 | 回环自检通过 |
| M1 | `x11` 采集 + ROI 标定 + `dir` 回放 | 同一帧反复取到同一块图；回放模式可跑 |
| M2 | `yuanshen-tiles` + 定位 + 节流 | 静止点读数稳定，与网页地图吻合 |
| M3 | 端口化收尾 + `cli` 适配器 + 降级 | FR-11/12/13 全绿，连续 30 分钟无异常 |

## 8. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 小地图被任务圈/迷雾遮挡 | 置信度低 | 掩膜；短暂沿用上次值 |
| 游戏改版改小地图样式 | 匹配失效 | ROI/掩膜/模板全在配置里 |
| 瓦片地址或版本变化 | 底图取不到 | 首次下载后本地缓存 |
| 显示端被误认为外挂 | 争议 | 只截屏、不注入；文档写清白 |
| 早期过度抽象 | 拖慢进度 | 端口只定 5 个，不引入插件系统/DLL/事件总栈框架 |
